# Open Source Projects

This repository contains two projects for the Open Source Technologies subject.

## 1. Open Source Migration Case Study
A case study on replacing proprietary software with open-source alternatives such as LibreOffice, GitLab CE, PostgreSQL, GIMP, Jitsi Meet, and Linux.

## 2. Open Source Documentation Improvement
Improving repository documentation with a README, installation and usage instructions, contribution guidelines, issue templates, and Git conventions.
